# ✈️ Flight Search App

A Flask web application for querying an airline database — multi-table joins, admin panel, and deployed live.

## Features (planned)
- Find airline by passenger age range
- Count airport visitors for an airline
- Find alternative flights between two cities
- Rank airlines by fleet & flight counts
- Admin: update passenger loyalty tiers

## Tech Stack (planned)
- Python 3.11+
- Flask · Flask-SQLAlchemy · Flask-Login
- MySQL (PyMySQL driver)
- Jinja2 templates
- pytest
